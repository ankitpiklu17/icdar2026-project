Multi-Modal Heterogeneous Music Notation Recognition from Documents

Framework for Real-Time Symbolic-to-Immersive Mapping

International Conference on Document Analysis and Recognition (ICDAR) 2026

Ankit Sinha · Atanu Saha · Chiranjoy Chattopadhyay · Rahul Kumar Ray

📄 Paper 💻 Code 📦 Dataset 📊 Poster 🎥 Video

Abstract

This paper introduces a unified framework for heterogeneous music notation recognition that supports multiple notation styles including orchestral and percussion scores. The proposed pipeline integrates document analysis, symbol detection, MusicXML generation, and symbolic-to-immersive mapping for real-time XR applications.

Key Contributions

  • First unified heterogeneous music notation recognition framework.
  • Supports orchestral and percussion notation.
  • Strip-wise document processing for robust recognition.
  • Automatic MusicXML generation.
  • Real-time symbolic-to-immersive mapping for XR learning.

Methodology

Our framework consists of four major stages:

  1. Document preprocessing
  2. Music symbol detection
  3. MusicXML generation
  4. XR visualization

Dataset

The proposed framework is evaluated using a heterogeneous dataset constructed from SWARA percussion notation and DeepScores V2.

Experimental Results

The proposed approach demonstrates strong performance on heterogeneous music notation recognition and produces accurate MusicXML outputs suitable for immersive visualization.
